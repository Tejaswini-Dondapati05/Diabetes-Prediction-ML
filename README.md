# Diabetes Prediction Using Machine Learning

## Project Description
This project focuses on predicting diabetes using Machine Learning techniques. It analyzes patient health-related data and predicts the possibility of diabetes using trained ML models.

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit (if used)

## Features
- Data preprocessing
- Exploratory Data Analysis
- Model training and testing
- Diabetes prediction
- Model evaluation
